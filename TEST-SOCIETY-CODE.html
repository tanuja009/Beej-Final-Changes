🌾 Society Code Auto-Fetch

Testing Guide for v1.7.0 - Public Society Registration Form

⚠️ IMPORTANT - Clear Cache First!
Before testing, you MUST clear your browser cache:
• Press Ctrl + Shift + R (Windows/Linux)
• Press Cmd + Shift + R (Mac)
• Or close browser completely and reopen

📋 How to Access the Form

1 Open index.html in your browser
2 You'll see the Beej Sangh Login Page
3 Click the green "Register Here" button at the bottom
4 Public Society Registration Form will open
5 Find the "Society Code" field (first field in Society Information section)

🧪 Test Cases

Test 1: Full Auto-Fill (Existing Society)

Objective: Verify all fields auto-fill with complete data
1 In the Society Code field, type: SOC-001
2 Press Tab key or click on the next field
✓ Expected Results:
• Success alert appears: "Society data found for SOC-001!"
• Society Code field turns green for 2 seconds
• ALL these fields auto-fill:
  - Society Name: "Rampur Krishi Samiti"
  - Society Type: "Farmers Cooperative"
  - Registration Number: "REG-MP-2020-001"
  - Registration Date: "2020-04-15"
  - Address, Village, Block, District, PIN Code
  - Contact Person Name, Mobile, Email
  - Bank Name, Branch, Account Number, IFSC Code

Test 2: Prevent Duplicate Registration

Objective: Verify system prevents duplicate active society registration
1 Refresh the page to clear the form
2 Type: SOC-001 (this society is Active)
3 Press Tab
✓ Expected Results:
• Warning alert appears: "Society ... is already registered and active"
• Society Code field is cleared
• Form fields remain empty (no auto-fill)
• User is advised to contact admin

Test 3: Basic Auto-Fill

Objective: Verify basic fields auto-fill for societies with limited data
1 Type: SOC-004
2 Press Tab
✓ Expected Results:
• Success alert appears
• Society Code field turns green
• Society Name: "Patan Krishi Vikas Samiti"
• District: "Chhindwara"
• Other fields remain empty (for manual entry)

Test 4: New Society Code (Not Found)

Objective: Verify no error when entering new society code
1 Type: SOC-999
2 Press Tab
✓ Expected Results:
• No alert (silent, non-intrusive)
• No auto-fill
• User can continue filling form manually
• No error messages

Test 5: Empty Field

Objective: Verify no action when field is left empty
1 Leave Society Code field empty
2 Press Tab
✓ Expected Results:
• No alert
• No auto-fill
• No action taken
• User continues to next field normally

Test 6: Auto-Uppercase Conversion

Objective: Verify code converts to uppercase automatically
1 Type in lowercase: soc-002
2 Press Tab
✓ Expected Results:
• Code automatically changes to: SOC-002
• Auto-fetch works normally
• Fields auto-fill if society found

🔍 What to Check

Visual Feedback:
• Society Code field should have green background/border for 2 seconds on success
• Helper text "Enter code to auto-fill data" should be visible below field
Alert Messages:
• Success: "Society data found for SOC-XXX! ... details have been auto-filled..."
• Warning: "Society ... is already registered and active. Please contact admin..."
• No error for unknown codes (silent behavior)
Field Population:
• Check ALL fields are filled when using SOC-001, SOC-002, SOC-003
• Only Society Name and District filled for SOC-004
• No fields filled for SOC-999 or other unknown codes
Duplicate Prevention:
• SOC-001 should show warning and clear field (because status = Active)
• SOC-003 should auto-fill normally (because status = Pending, not Active)
✅ Success Criteria
All 6 test cases pass without errors, and:
• Auto-fetch works for existing codes
• Duplicate active registrations are prevented
• New codes don't cause errors
• Visual feedback is clear and helpful
• Form remains usable throughout all scenarios

🐛 Troubleshooting

Problem: Changes not appearing
Solution: Clear browser cache (Ctrl+Shift+R) or close/reopen browser
Problem: Auto-fetch not working
Solution: Check browser console (F12) for JavaScript errors
Problem: Fields not auto-filling
Solution: Verify you're using valid demo codes (SOC-001, SOC-002, etc.)
Problem: Page not loading
Solution: Ensure all JavaScript files are in the same folder as index.html
