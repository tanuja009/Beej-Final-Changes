How to Run the Application

⚠️ STOP! Do NOT Open index.html Directly!

Double-clicking index.html will NOT work!
Browser security blocks CSS and JavaScript when using file:// protocol.
You must run the application through a local web server.

🚀 Method 1: Use Batch Files EASIEST

Step 1: Start the Server

  1. Find and double-click: START-SERVER.bat
  2. A black command window will open
  3. Wait for message: "Serving HTTP on :: port 8000"
  4. Keep this window OPEN (do not close it)

Step 2: Open the Application

  1. Find and double-click: OPEN-APPLICATION.bat
  2. Your browser will automatically open
  3. URL will be: http://localhost:8000/index.html
  4. ✅ Application will load with full styling!
▶️ START-SERVER.bat 🌐 OPEN-APPLICATION.bat

💻 Method 2: Manual Command Line

  1. Open Command Prompt (CMD)
  2. Navigate to project folder:
cd "c:\Users\hp\Desktop\Projects Folder\Beej Sangh\Breeder Module Wireframe"
  1. Start Python server:
python -m http.server 8000
  1. Open browser and go to:
http://localhost:8000/index.html

✅ What You Should See When Running Correctly:

  • ✓ URL shows: http://localhost:8000/index.html (NOT file:///)
  • ✓ Green gradient background on login page
  • ✓ White login card with proper styling
  • ✓ All buttons are green (#4CAF50)
  • ✓ Light green background on dashboard (#f1f8e9)
  • ✓ Dark green sidebar with white text
  • ✓ White stat cards with colored borders
  • ✓ All text is crisp and properly formatted

📌 Quick Reminder:

Always use START-SERVER.bat first, then OPEN-APPLICATION.bat
Keep the server window open while using the application.
To stop: Close browser, then press Ctrl+C in the server window.
